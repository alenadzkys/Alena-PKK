# COFNA – Coffee Ordering Website

**COFNA** merupakan website pemesanan kopi berbasis web yang dikembangkan untuk memudahkan pelanggan dalam melihat pilihan menu kopi dan non-kopi serta melakukan pemesanan secara online.

Website ini dibuat menggunakan HTML, CSS, PHP, dan MySQL dengan bantuan Laragon sebagai server lokal. COFNA memiliki tampilan sederhana dengan perpaduan warna cream dan cokelat yang memberikan kesan hangat dan nyaman.

**Fitur utama COFNA:**
1. **Home** – Halaman utama yang menampilkan informasi dan pengenalan COFNA.
2. **Menu** – Menampilkan berbagai pilihan minuman kopi dan non-kopi beserta harga.
3. **Keranjang** – Menyimpan dan menampilkan menu yang dipilih pelanggan.
4. **Tentang Kami** – Menampilkan informasi mengenai COFNA.
5. **Login dan Register** – Memungkinkan pengguna membuat akun dan masuk ke website.
6. **Admin Dashboard** – Digunakan admin untuk mengelola informasi dan data website.
7. **Logout** – Mengakhiri sesi akun pengguna.

**Teknologi yang digunakan:**
- HTML
- CSS
- PHP
- JavaScript
- MySQL
- Laragon

**Tujuan Project:**

Membuat website pemesanan kopi yang praktis, mudah digunakan, dan dapat dikembangkan agar bisa diakses oleh pelanggan secara online.
